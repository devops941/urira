# UYIRA — Professional UI/UX Color System Implementation

You are a Senior UI/UX Designer and React Native Developer.

Implement a professional, modern, accessible, and responsive UI design system for my mobile application.

## Application Details

- App Name: UYIRA
- App Type: Smart Health Monitoring Application
- Platform: Android and iOS
- Framework: React Native + Expo + TypeScript
- Backend: Node.js + Express.js
- Database: MongoDB
- Target Users: Kids, teenagers, young adults, adults, and senior citizens
- Audience: All genders

## 1. Brand Color Palette

Use the following exact brand colors consistently throughout the application.

- Primary: Deep Forest Green — `#12372A`
- Secondary: Soft Mint — `#E8F3EC`
- Surface: Pure White — `#FFFFFF`
- Primary Text: Charcoal — `#1F2937`
- Secondary Text: Slate Gray — `#64748B`

### Brand Color Usage

- Use Deep Forest Green for primary buttons, active navigation, logo, key headings, and important actions.
- Use Soft Mint for wellness cards, selected states, and subtle background sections.
- Use Pure White for main screen backgrounds, cards, forms, and modals.
- Use Charcoal for titles, labels, and important text.
- Use Slate Gray for descriptions, timestamps, and secondary information.
- Maintain a clean, minimal, premium healthcare interface.
- Avoid unnecessary gradients, excessive shadows, and oversaturated backgrounds.

## 2. Health Feature Color Categories

Use these exact colors for their corresponding health modules.

- Activity & Steps: Blue `#0EA5E9`
- Sleep: Violet `#8B5CF6`
- Nutrition & Calories: Orange `#F97316`
- Water Intake: Cyan `#06B6D4`
- Heart Rate & Vitals: Rose Red `#E11D48`
- Goals & Healthy Habits: Green `#16A34A`

Use each feature color consistently for:
- Feature icons
- Charts and graphs
- Progress indicators
- Small highlights
- Feature-specific cards

Do not use feature colors as the main application brand color. The brand should remain Deep Forest Green.

## 3. UI Design Guidelines

- Use a modern, premium, minimalist healthcare design.
- Use white and off-white backgrounds.
- Use rounded cards with consistent corner radii.
- Use subtle borders and minimal shadows.
- Maintain consistent spacing and typography.
- Use clear icons and readable labels.
- Ensure responsive layouts for different mobile screen sizes.
- Support accessibility and readable font sizes.
- Do not use gender-specific color restrictions.
- Allow optional font-size adjustments for senior users.
- Never communicate medical status using color alone; include labels and icons.

## 4. Dashboard Design

Create a professional health dashboard containing:

- Personalized greeting
- User profile and notification icons
- Today's health summary
- Activity and step count
- Sleep duration
- Nutrition and calorie tracking
- Water intake
- Heart rate and vital signs
- Daily goals and progress
- Health analytics and reports
- Bottom navigation

Use Deep Forest Green for the main dashboard summary and primary actions. Use each health category's dedicated color for its corresponding metric.

## 5. Implementation Requirements

- Create reusable color constants.
- Avoid hardcoding color values inside individual components.
- Use a centralized theme system.
- Support light and dark theme preparation.
- Maintain consistent design tokens.
- Use TypeScript types for theme values.
- Keep components reusable, maintainable, and scalable.

Create a professional production-ready UYIRA design system that looks consistent across all screens and is suitable for users of every age group and gender.
